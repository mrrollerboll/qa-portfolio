# Тест-кейс: Авторизация пользователя

**ID:** TC-001
**Модуль:** Авторизация
**Приоритет:** High

## Предусловия
- Пользователь зарегистрирован в системе
- Открыта страница входа

## Шаги воспроизведения
1. Ввести корректный логин в поле "Email"
2. Ввести корректный пароль в поле "Password"
3. Нажать кнопку "Войти"

## Ожидаемый результат
Пользователь успешно авторизован и перенаправлен на главную страницу личного кабинета.

## Фактический результат
Совпадает с ожидаемым.

## Статус
Passed
